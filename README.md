# 🎼 图解和声 · 交互阅读版（基础篇 + 进阶篇）

> 📖 **在线阅读**：<https://animerqi.github.io/harmony-reader/>

《图解和声》（叶小胖）的交互式阅读工具——**代替电子书来读**，纯静态、离线可用：

- 📖 **完整原文**：**基础篇**（第一~十章 + 附录，300 小节）+ **进阶篇**（第十一章 转调、第十二章 调式、第十三章 现代和声 + 附录四，27 小节），共 15 章、300+ 小节
- ♪ **能听的和弦进行**：书里**文字直接标出的进行**自动识别为音频块（**639 个**），点一下就能听，带和弦高亮与循环
- 🎹 **能听的谱例**：**604 个图片谱例**通过 OMR（homr）转录成 MIDI，图片下方一键播放；**39 组"多图谱例"**（一个谱例横跨多张图）已拼接为**完整谱例**播放
- 🖼️ **谱例图**：全部本地化（基础篇 840 张 + 进阶篇 636 张，共 1476 个文件/1699 处引用），点击放大
- 🎼 **移调练习**：3-2「移调」节内附完整练习卡（《星语心愿》可移调播放、书例对比）
- 🌙 **暗色模式** + 🔁 **循环播放** + 🎚️ **播放设置**（7 种伴奏风格 / 6 种音色 / 和弦时值 / 速度）

## 怎么打开

### 在线
直接访问 **<https://animerqi.github.io/harmony-reader/>**（GitHub Pages，随仓库自动部署）。

### 本地（电脑）
直接**双击 index.html** 即可（Chrome / Edge / Firefox）。或本地服务器：

```bash
python -m http.server 8765     # 在 harmony-trainer 目录
# 浏览器打开 http://127.0.0.1:8765
```

### 手机 / 平板
电脑起服务器后，手机连同一 WiFi 访问 `http://电脑IP:8765`（`ipconfig` 查 IP）。
窄屏自动切换为上下布局，目录在内容上方。

## 数据说明

- 原文与和弦进行由脚本从 EPUB 自动提取（`scripts/extract_ch23.py`、`scripts/extract_adv.py`，可复现）；
- 音频块 = 书中文字直接写明的和弦进行（如 "Am—Em—Am"、"I—vi—IV—V"），自动解析成音高数据；
- 级数进行按章节语境默认调性解析：第三章默认 a 小调、其余章默认 C 大调，文中明确给出调性的按文中调；
- **谱例 MIDI**：图片用 homr（ONNX 乐谱识别）转 MusicXML → music21 转 MIDI → mido 解析为音符数据（`omr_test/` 批量管线）；多图谱例采用"逐张识别 → 时间轴拼接"（路线 B），低清图用"垂直拼接 → 整张识别"（路线 A）补充；
- 音频由浏览器 Web Audio 实时合成（6 种音色），完全离线，不依赖任何外部服务。

## 部署到 GitHub Pages

项目为纯静态站点，已配置 `.github/workflows/pages.yml` 自动部署：

1. **创建 GitHub 仓库**（Public 或 Private 均可，注意 Pages 站点对公众可见）
2. 本地推送：
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```
3. **开启 Pages**（二选一）：
   - 方式 A（简单）：仓库 Settings → Pages → Source 选 **Deploy from a branch** → main / root
   - 方式 B（推荐）：Source 选 **GitHub Actions**（仓库已内置 workflow，推送后自动部署）
4. 访问：`https://<用户名>.github.io/<仓库名>/`

> 部署前已做适配：图片文件名 `!` → `_`、localStorage key 加 `harmony-` 前缀（自动迁移旧数据）。
> 之后每次更新页面/数据，`git push` 即可自动发布。
