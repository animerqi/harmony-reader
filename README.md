# 🎼 图解和声 · 交互阅读版（基础篇 + 进阶篇）

《图解和声》（叶小胖）的交互式阅读工具——**代替电子书来读**：

- 📖 **完整原文**：**基础篇**（第一~十章 + 附录，300 小节）+ **进阶篇**（第十一章 转调、第十二章 调式、第十三章 现代和声 + 附录四，27 小节）
- ♪ **能听的和弦进行**：书里**文字直接标出的进行**自动识别为音频块（**639 个**），点一下就能听；**图片谱例暂不配音频**
- 🖼️ **谱例图**：全部本地化（基础篇 840 张 + 进阶篇 636 张，共 1476 个文件/1699 处引用），点击放大
- 🎹 **移调练习**：3-2「移调」节内附完整练习卡（《星语心愿》可移调播放、书例对比）
- 🌙 **暗色模式**：右上角按钮手动切换，记忆偏好
- 🔁 **循环播放**：每个音频卡片都有循环开关

## 文件

```
harmony-trainer/
├── index.html      # 阅读器（单页应用）
├── chapters.js     # 全书数据（第一~十章+附录原文 + 510 个音频块数据）
├── images/         # 谱例图片（840 张）
└── README.md
```

## 怎么打开

### 电脑（推荐宽屏）
直接**双击 index.html** 即可（Chrome / Edge / Firefox）。或本地服务器：

```bash
python -m http.server 8765     # 在 harmony-trainer 目录
# 浏览器打开 http://127.0.0.1:8765
```

### 手机 / 平板
电脑起服务器后，手机连同一 WiFi 访问 `http://电脑IP:8765`（`ipconfig` 查 IP）。
窄屏自动切换为上下布局，目录在内容上方。

## 功能

| 功能 | 说明 |
|---|---|
| 📚 目录导航 | 章 › 分组 › 小节 树形目录，点击加载内容 |
| ♪ 音频块 | 每个文字标出的和弦进行自动生成可播放卡片（带和弦 chips，播放时高亮，可循环） |
| ⚙️ 设置面板 | 顶栏 ⚙️ 打开：阅读（字体/字号/行距）+ 播放（风格/时值/音色/速度/旋律），全部自动保存 |
| 🎹 伴奏风格 | 7 种织体：柱式 / 分解 / 琶音 / 民谣 / 华尔兹 / 切分 / 摇摆 |
| 🎼 音色 | 6 种合成音色：钢琴 / 电钢 / 风琴 / 口哨 / 大键琴 / 木琴（Web Audio 谐波合成） |
| ⏱️ 和弦时值 | 每和弦 2/3/4 拍可选（默认 2 拍）；3拍+华尔兹=圆舞曲，4拍+民谣=流行伴奏 |
| 📖 阅读设置 | 像电子书一样调字体（默认/宋体/楷体/黑体）、字号（小/中/大/特大）、行距（紧凑/标准/宽松）|
| 🎚️ 移调练习 | 「移调」节内的《星语心愿》练习：±7 半音移调、旋律开关、循环、书例 a⇄b 对比 |
| 🌙 暗色模式 | 手动切换，localStorage 记忆 |
| 🖼️ 图片放大 | 点击谱例图全屏查看 |
| ⌨️ 快捷键 | Space 播放/停止 · 1-7 切风格 · 8/9/0 切时值(2/3/4拍) · 移调练习内 ←→ 移调 |

## 数据说明

- 原文与进行识别由脚本从 EPUB 自动提取（`scripts/extract_ch23.py`，可复现）；
- 音频块 = 书中文字直接写明的和弦进行（如 "Am—Em—Am"、"I—vi—IV—V"），自动解析成音高数据；
- 级数进行按章节语境默认调性解析：第三章默认 a 小调、其余章默认 C 大调，文中明确给出调性的按文中调；
- 音频由浏览器 Web Audio 实时合成（6 种音色），完全离线。

## 部署到 GitHub Pages

项目为纯静态站点，可直接部署到 GitHub Pages：

1. **创建 GitHub 仓库**（Public 或 Private 均可，注意 Pages 站点对公众可见）
2. 本地推送：
   ```bash
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```
3. **开启 Pages**（二选一）：
   - 方式 A（简单）：仓库 Settings → Pages → Source 选 **Deploy from a branch** → main / root
   - 方式 B（推荐）：Source 选 **GitHub Actions**（仓库已内置 `.github/workflows/pages.yml`，推送后自动部署）
4. 访问：`https://<用户名>.github.io/<仓库名>/`

> 部署前已做适配：图片文件名 `!` → `_`、localStorage key 加 `harmony-` 前缀（自动迁移旧数据）。
> 之后每次更新页面/数据，`git push` 即可自动发布。
